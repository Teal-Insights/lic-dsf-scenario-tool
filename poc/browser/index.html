Proof of concept

LIC-DSF calculation in the browser

This page runs the pinned lic-dsf-2025-08-12 library on your computer. It is not a release and it is not an Excel verification.

Choose the workbook each visit. The file stays in this tab's memory and is not uploaded or saved by the page. The case you pick is remembered in local storage for that workbook's fingerprint.

The Python runtime is downloaded from jsDelivr. That request does not include the workbook.
