# Bundled open fonts

IBM Plex Serif SemiBold (version3.006) and Inter Regular/SemiBold (version4.001) are unmodified OpenType font files under the SIL Open Font License1.1. The notices are included beside them. They are separate from the software MIT license.

Upstream: https://github.com/IBM/plex and https://github.com/rsms/inter . Both the browser and chart renderer load these local files. No font service, network request or user installation is needed.
